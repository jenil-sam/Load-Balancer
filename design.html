Project Overview

This project simulates a production-grade load balancer that distributes incoming web requests across a dynamic pool of web servers. The system models real-world behaviors including auto-scaling, IP-based firewall protection, job type routing, and detailed activity logging.

Auto-Scaling Algorithm

// Called every clock cycle, but throttled by scaleWait function autoScale(): if (currentCycle - lastScaleCycle) < scaleWait: return // too soon — wait before scaling again n = servers.size() q = queue.size() if q > maxQueue * n: // e.g., queue > 80 * n addServer() // SCALE UP lastScaleCycle = currentCycle else if q < minQueue * n AND n > 1: // e.g., queue < 50 * n removeIdleServer() // SCALE DOWN lastScaleCycle = currentCycle

Per-Cycle Simulation Loop

for cycle = 1 to totalCycles: // 1. Inject new requests periodically if cycle % newReqInterval == 0: injectRandomRequests(1..5) // filtered by IP firewall // 2. Assign queue requests to idle servers distributeRequests() // 3. Advance all servers by one clock tick tickAllServers() // servers that finish increment completedCount // 4. Check if scaling is needed autoScale() // 5. Log status every 500 cycles if cycle % 500 == 0: logStatus()
